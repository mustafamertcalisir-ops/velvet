# QA fixtures — fixture community photography (internal test material only)

These photographs exist only so the member vertical slice can be visually
QA'd with realistic composition (DEC-037, DEC-057).

- They are NEVER bundled into the app: nothing under `e2e/` is imported by
  `src/`. The E2E harness serves them at `/__qa/members/…` and passes the
  URLs to the development-only `seedCommunity` fixture at run time.
- They must never be used as member imagery, marketing or brand photography.
- The people pictured are not the fixture members; names, work and cities
  in `src/dev/communityFixture.ts` are invented.
