# Admission app (brand name not finalised — "Velvet" is a placeholder)

Private-membership dating & social discovery app, Türkiye-first.

Built so far: phone verification → Stage 1 application → status → Stage 2
extended application → final review → decision → membership activation →
the first member slice (welcome, Dating setup, profile confirmation, today's
Dating introductions, pass/like, match, conversation, You, safety) — and a
production API on PostgreSQL behind the same ports (`server/`).

## Run

```bash
npm install
npx expo start            # Expo Go / dev build / web — uses the in-app mock backend
```

Against the real API (local PostgreSQL):

```bash
cd server && npm install && DATABASE_URL=postgres://… APP_ENV=development DEV_SEED=1 npm run dev
EXPO_PUBLIC_BACKEND=http EXPO_PUBLIC_API_URL=http://127.0.0.1:8787 npx expo start
```

The **mock** backend's verification code is **246810** (development only —
the mock is not bundled in release builds; the API sends random codes).
To show development UI (the OTP hint and reviewer-simulation controls):

```bash
EXPO_PUBLIC_ADMISSION_DEV_PANEL=1 npx expo start
```

Release builds (`EXPO_PUBLIC_APP_ENV=production`, `eas.json`) always use the
API at `EXPO_PUBLIC_API_URL` (https) and contain no mock, fixtures or
development tooling. See DEC-030, DEC-059, DEC-061.

## Check

```bash
npm run verify              # everything below, in order
npm run typecheck
npm run lint
npm test                    # app unit + store integration (mock server)
npm run server:typecheck
npm run server:test         # API integration tests on a real PostgreSQL
npm run server:build
npm run build:web:qa        # dist/      — mock backend, dev hooks on, dev panel off
npm run build:web:prod      # dist-prod/ — production env, HTTP backend (API URL inlined)
npm run check:release       # strict gate (https API); check:release:local allows 127.0.0.1
npm run e2e                 # Chromium, 3 widths on the mock + the release bundle against the real API
npm run build:native-bundles
python3 scripts/check-fonts.py
```

Typed routes are generated by `expo start`; after adding a route, start the
dev server once before `npm run typecheck`. `npm run e2e` expects Chromium at
`/opt/pw-browsers/chromium` or `CHROMIUM_PATH`, local PostgreSQL binaries
(or `TEST_DATABASE_URL`), and a built `server/dist`.
